Savannah Dash

My game is inspired by Crossy Road, where players have to navigate through a Savannah environment and avoid moving animals. The aim of the game is to travel as far as you can and earn points without losing all three lives. Players use the arrow keys to move their player. Link to Savannah Dash: https://makecode.com/_503EYFJyLTYa
